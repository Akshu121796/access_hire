# ♿ AccessHire
 An inclusive hiring platform designed to connect Persons with Disabilities (PwDs) with accessible employment opportunities while helping recruiters build diverse workplaces.

## 📌 Overview
AccessHire is a web-based hiring platform built to make recruitment more inclusive and accessible for Persons with Disabilities (PwDs).

The platform allows job seekers to discover opportunities that match their skills while enabling recruiters to post jobs, manage applications, and create an accessible hiring experience.

## 🚀 Features
### 👨‍💼 For Job Seekers
- Secure authentication
- Browse available job opportunities
- Apply for jobs
- Accessible and responsive interface
- Personalized dashboard

### 🏢 For Recruiters
- Recruiter authentication
- Post and manage job listings
- View applications
- Track candidates
- Manage hiring workflow

## ⚙️ Installation
Clone the repository

```bash
git clone https://github.com/Akshu121796/access_hire.git
```

Navigate into the project

```bash
cd access_hire
```

Install dependencies

```bash
npm install
```

Create a `.env.local` file and configure your Firebase credentials.

Run the development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
